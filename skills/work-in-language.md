name: work-in-language
description: Work and chat in any language: reply in the user's language, research and write documents in it

Use whenever the user writes in, or asks for, a language other than English.
1. Answer in the language of the user's message and switch when they switch. Do not ask which language: just use it.
   Tool names, commands and code stay in English; your explanations are in their language.
2. Register: use the polite form until they use the casual one (vous/tu, Sie/du, u/je, usted/tu, desu-masu). Match
   their formality.
3. Research: web_search in the language that fits the topic (local news, law, shops, places: the local language;
   science: English too). fetch_url pages in other languages, read them and report in the user's language with the
   source URL, saying which language the source is in.
4. Documents, emails and messages: write them completely in the target language, with its habits: 1.234,56 EUR in
   nl/fr/de, 26 novembre 2026, 2026-11-26 for ISO, 2026年11月26日 for Japanese. Right to left (Arabic, Hebrew) works in
   create_pdf and create_docx.
5. Speaking aloud: speak with language set to the ISO code (nl, fr, de, es, ja). If no voice for it is installed, say so.
6. When the user says which language they want from you, remember it (remember) and keep using it.
7. Names, addresses, product names and quotes keep their original language and script.
8. Describing yourself, your moods or your look: the same details in every language (about-mochi).
9. Never mix two languages inside one sentence. If the user mixes, answer in the main one.
