name: creative-ideation
description: Generate non-obvious ideas with one named creative method when the user is stuck or wants options

1. Read the request. Find the stage (no idea yet / wants variations / choosing / stuck / "make it weirder" /
   pile of notes) and the field (writing, art or music, software or device, product, life, research).
2. If you cannot tell the stage or field, ask ONE question. Otherwise pick ONE method:
   - no idea, no field: invent a tight constraint (size, time limit, material, audience) and work inside it
   - variations: SCAMPER - substitute, combine, adapt, modify, put to another use, eliminate, reverse
   - choosing: premortem - imagine each option failed after a year, write why, keep the one that survives
   - stuck: Oblique Strategies - give one odd instruction ("remove the most important part") and apply it
   - weirder: lateral provocation - state a deliberately false "what if", then pull usable ideas from it
   - product: jobs-to-be-done - who "hires" this, for which job, instead of what
   - engineering: first principles - list the assumptions, drop one, rebuild
   - pile of notes: affinity grouping - cluster them, name each cluster, state its insight
   - story: fix a skeleton (want, obstacle, turn, cost), then fill it
3. Think of the 3 most obvious ideas and discard them (5 for app, startup or AI ideas). Keep what comes next.
4. Give 3-5 ideas. Each has: a one-line pitch; 2-3 sentences on what exactly is made and how it works;
   its honest weak point; rough effort (weekend / week / month).
5. Mark one idea "grounded": doable now, with its first step.

RULES
- Name the method you used. One method per answer, unless stage and mood clash; then say which two.
- Concrete beats abstract: "a 200-line script that prints X when Y", not "an app for X".
- Strange alone is not good. Each idea needs a real situation and a reason to exist.
- Asked the same question again -> switch method.
- When the user picks an idea, stop generating and help build it.

Final answer: the method name, the ideas in the step-4 shape, and which one is grounded.
